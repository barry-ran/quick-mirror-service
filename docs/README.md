## 给开发 agent 的初始指令

请按本目录 PRD1.2 和技术文档开发极限投屏无ADB独立版本。先读取仓库说明，执行T00基线核对，再按T01–T10依赖推进，在各受影响仓库的独立分支实现。复用现有PC UI、解码、群控和二进制协议，APK基于AutoX QuickMirror，仅支持单JS，无AutoX定时任务。不能直接复制scrcpy-apk的58–61控制消息，因为与PC协议冲突。Peerloom须取消本产品固定设备数量限制，处理操作额度、目标独占、自定义TURN和ARM32。截图与投屏共用授权采集。单手机一PC，连接/断开与停止画面分开，不新增配对确认。完成必要测试和文档，真实报告未能验证的规模、平台或生产依赖。

## 需要先查实的实施依赖

甲方已确认一期暂不接入现有账号 token 的服务端校验，不作为开工或发布前置条件。PC原有登录、收费及授权逻辑保持不变；新服务仅验证Peerloom安装实例及会话。正式签名和规模测试设备由实施环境提供。文档中的新增API和模块是开发目标，不能视为已经存在。
