# 安装身份模块

本模块通过 Peerloom 已有公开 `GET /v1/device-self` 验证安装凭证，不查询 Peerloom 私有数据库，不导入其源码，不验证原产品付费账号。

```mermaid
sequenceDiagram
    participant B as 业务模块
    participant A as 身份适配器
    participant P as Peerloom 公开接口
    B->>A: 安装凭证与请求上下文
    A->>P: HTTPS GET device-self
    P-->>A: 权威 device tenant application
    A->>A: 校验租户和 application 映射
    A-->>B: 安装主体或脱敏错误
```

## 信任边界

部署配置指定同一产品租户和两个不同 application UUID，分别对应 PC、手机。请求方不能选择角色，响应中的 platform 和 metadata 也不能升级角色。每次调用重新请求权威服务，无缓存放行、无本地解码 opaque token、无信任 isLoggedIn 的分支。

HTTP client 强制 HTTPS origin、拒绝重定向，超时不超过五秒，响应最多 64 KiB。请求上下文取消会终止请求；异常只返回稳定错误码，不传递内部响应、网络细节或凭证。私有 CA 可通过部署侧 Transport 信任配置接入，不提供跳过 TLS 验证的产品开关。

## 已验证及未实现边界

单元测试覆盖真实本地 TLS 请求、角色混淆、跨租户、撤销凭证、限流、上游错误、截断/超大 JSON、重定向、非法凭证和取消，并使用 race detector。这里不把 HTTP 测试服务器称为真实 Peerloom 联调。

正式Peerloom v0.1.3的device-self响应包含本次凭证到期时间。`VerifyCredential` 读取同一认证响应中的 `credential_expires_at`（RFC3339Nano），缺失、null、错误类型、无时区或零时间均失败关闭；不会退回只校验主体的 `Verify`，也不接受客户端自报期限。期限归一到UTC，15分钟上界及到期比较仍由业务存储使用数据库时钟处理。

该适配器已完成本地TLS契约测试及正式v0.1.3包公开接口实际联调，包含纳秒精度、旧新凭证不同重叠期、撤销/错误响应不泄漏主体。exchange与目录接口已挂载运行时，并用正式上游/verify-full业务PG/HTTPS进程实测通过；客户端安全持久化和完整会话链路仍需各端独立验收。目标独占与会话级自定义 TURN 同样等待公开能力落地，不以多个 grant 的单会话配额冒充目标独占。
